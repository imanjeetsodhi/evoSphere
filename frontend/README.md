# EvoSphere Frontend

The frontend is the browser-based 3D ecosystem experience for [EvoSphere](../README.md).

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` - Landing page
- `/world` - Interactive ecosystem simulator
- `/analytics` - Research and ecological analytics
- `/codex` - Species Codex
- `/worlds` - Biome presets

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

See the [repository README](../README.md) for the complete architecture, setup instructions, API documentation, and development notes.
